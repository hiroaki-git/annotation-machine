# annotation-machine

C# (WPF) で開発した、COCO WholeBody形式（BBox・キーポイント）に特化したアノテーションツールです。

## 🌟 特徴
* **スタンドアロン動作:** 煩雑なサーバー構築や環境設定が不要で、単体ですぐに起動できます。
* **特化型デザイン:** オブジェクト検出（BBox）とキーポイント（点）の付与に集中した、シンプルで快適な操作性を実現しています。

## 🚀 導入・使い方

1. [Releases](../../releases) ページから最新の実行ファイル（.exe）をダウンロードします。
2. 任意のフォルダに展開し、`AnnotationMachine.exe` を実行してください。
